Boss-Recorder

Gewonnene Bosskämpfe aufnehmen, Tode zählen, Siege auf YouTube.

Boss-Recorder ist ein privates Werkzeug für Windows. Es beobachtet das Spielbild, erkennt Bosskämpfe und schneidet nur die gewonnenen aus der laufenden Aufnahme von OBS Studio. Verlorene Versuche werden verworfen und nur gezählt: Pro Boss entsteht so eine Statistik mit Toden, Kampfzeit und dem knappsten Versuch.

So arbeitet das Programm

  • Es läuft ausschließlich auf dem eigenen PC. Es gibt keinen Server, kein Benutzerkonto beim Entwickler und keine Weitergabe von Daten.
  • Es greift nicht in Spiele ein, sondern liest nur das Bild und steuert OBS Studio über dessen lokale Schnittstelle.
  • Auf Wunsch lädt es gewonnene Kämpfe auf den eigenen YouTube-Kanal hoch.

Zugriff auf YouTube

Für den Upload nutzt Boss-Recorder die YouTube API Services (YouTube Data API v3). Nach deiner Zustimmung im Google-Anmeldefenster lädt es Videos auf deinen Kanal hoch, legt eine Playlist pro Spiel an, fügt die Videos dort ein und fragt ab, ob YouTube ein Video fertig verarbeitet hat. Andere Videos, Kommentare oder Abos liest oder ändert es nicht.

Mit der Nutzung der YouTube-Funktionen stimmst du den YouTube-Nutzungsbedingungen zu. Für die Daten bei Google gilt die Datenschutzerklärung von Google. Den Zugriff kannst du jederzeit in den Sicherheitseinstellungen deines Google-Kontos widerrufen.
